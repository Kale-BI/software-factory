The machine that builds our software

Kale ships with a small team and a large number of agent sessions. A process that lives in habit is a process an agent cannot join — so ours is written down, argued from first principles, and published in full. Prompts included.

Agent sessions start with no memory of yesterday. That single fact is why the process is a document and not a habit.

The six principles
Humans decide. The tracker is the record. Evidence gates every transition. No AFK without a definition of done. Sessions sized to the smart zone. Attention is expensive.

The parts most teams keep private: the board's exact semantics, the skill tree that runs each stage, and the conventions that keep a tracker full of agents legible to humans.

The board
State transitions are the process, so every column means something exact — and every parked column is a claim about what a ticket waits for, never what anyone is doing to it.

The skill tree
Twenty skills, admitted by reference and placed by variance. Derived from the process, not accumulated — and cut from twenty-eight to prove it.

Evidence and dossiers
Agents write to the tracker like colleagues, not like log files: a one-breath note on the ticket, the long story in the effort's artefact, proof gating every transition.

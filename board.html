The board

State transitions are the process, so every column means something exact. This is the whole vocabulary — there is deliberately nothing else.

Columns

What is not here matters too. The board once had a "Ready to go" column — a parking state for plans awaiting verdicts, from a triage design since retired. When the machinery that needed it went, the column went with it. A state no stage reads is a state the process cannot explain, so the board keeps exactly the states the process uses.

Labels: what a ticket waits for

A label is a claim about what the ticket waits for — never about what anyone is currently doing to it. Four waiting states, applied by triage; unlabeled means untriaged.

LabelWaits forDispatched?
ready-for-agentNothing — an AFK session can start from the attached briefYes — the only label agents dispatch from
ready-for-humanHuman execution — the brief is complete but a step needs a personNo — the human work queue
needs-human-inputOne reply to a decision cardNo
needs-grillingA session — the questions are entangled or open-formNo

The full routing logic — how a label falls out of drafting the brief, and the five-clause test that separates a card from a session — is on the morning triage page.

Why the vocabulary is this small

Columns say where work is in the spine; labels say what parked work waits for. Neither ever says what someone is doing — activity is visible in the session and the PR, and duplicating it into state produces states that lie. Retired vocabulary is renamed, never deleted, so the history of closed tickets keeps making sense.

The board

State transitions are the process, so every column means something exact. This is the whole vocabulary — there is deliberately nothing else.

What is not here matters too. A state no stage reads is a state the process cannot explain, so the board keeps exactly the states the process uses — columns have been removed when the machinery that needed them went.

Routes: what a ticket waits for

Triage's four routes — ready-for-agent, ready-for-human, needs-decision, needs-grilling — are claims about what the ticket waits for, never about what anyone is doing to it. On this board each route is a column, so the board answers the question by itself and no route is ever a label. The full routing logic — how a route falls out of drafting the ticket, and the four-clause test that separates a card from a session — is on the triage page.

Why the vocabulary is this small

Columns say where work stands — in the spine or parked, and parked columns say what the ticket waits for. No column ever says what someone is doing — activity is visible in the session and the PR, and duplicating it into state produces states that lie. Retired vocabulary is renamed, never deleted, so the history of closed tickets keeps making sense.
